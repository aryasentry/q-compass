# Additive Next.js Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task.

**Goal:** Create a separate, working Next.js dashboard over the existing real-data research engine.
**Architecture:** Next.js :3000 → same-origin API proxy → FastAPI :8000 → existing package/SQLite worker. Streamlit :8501 remains unchanged.
**Tech Stack:** Next.js 16, React 19, TypeScript, SWR, Lucide, FastAPI, existing Python 3.12 package.
**Spec:** docs/superpowers/specs/2026-09-05-nextjs-design.md

## Global Constraints

- Keep `app/` and `.streamlit/` byte-for-byte unchanged.
- Authentic records and checksum-verified results only; unavailable is never a fabricated value.
- Local loopback services only, no deployment, no trading.
- Share JobStore and exclusive worker with Streamlit. GET is read-only.
- No arbitrary path, command or URL endpoints. Restrict ranker_path in web submissions.
- Do not stage or commit existing untracked literature or unrelated files.

### Task 1: Local API adapter

Files: create `src/qcompass/api/{__init__,app,repository}.py`, `tests/test_api.py`; modify `pyproject.toml` and `uv.lock` only for FastAPI/uvicorn dependencies.
Produces `create_app(root: Path | None = None, launch_worker: bool = True) -> FastAPI` and module `app`.

Contract (all prefixes `/api`):
- GET `/health` → `{status:'ok',mode:'simulation',worker_threads:4}`.
- GET `/datasets` → `{datasets:[manifest summary],warnings:[string]}`. Summary includes dataset_id, first_date,last_date,stock_count,row_count,fingerprint,quarantined_count, retrieved_at,crosscheck. Parse and verify metadata per-file, skip corrupt with warnings. No raw file download.
- GET `/datasets/{id}` → `{manifest, constituents:[{symbol,company?,sector,isin}], quarantine:[records]}` using full verify; small quarantine output capped 100 with count.
- POST `/datasets/{id}/verify` → `{valid:true,fingerprint}` full source verification.
- GET `/runs?limit=50` → `{runs:[{run_id,kind,created_at,dataset_id,as_of,n,k,seed,methods,feasible_methods,cancelled}],warnings:[]}` checksum verified per-file, malformed skipped. Include studies marked kind; UI may show separately.
- GET `/runs/{id}` → complete checksum-verified result; missing404/corrupt409.
- GET `/runs/{id}/export?format=json|csv` → download verified result or newly derived comparison CSV, never an unverified stale export.
- GET `/jobs` → `{jobs:[JobStore row without absolute result path, with result_id when experiment succeeded]}`.
- GET `/jobs/{id}` → `{job,events}`. Jobs may be submitted by Streamlit too.
- POST `/jobs` body `{config: RunConfig-compatible object, token:string}` → `{job_id}` status202; full snapshot verified before accepting; no ranker_path web read. Reusing token+same config returns same job; different config409. Preserve JobStore idempotency; serialize check+submit using local submission FileLock.
- POST `/jobs/{id}/cancel` → `{job_id,status,cancel_requested}`; missing404. No deletion.
- POST `/downloads` body `{token:string}` queues existing download job idempotently, status202.
- Every mutation requires `X-QCompass-Client: local-ui`, JSON body where applicable, and reject Origin unless exact http://localhost:3000 or http://127.0.0.1:3000. TrustedHost restrict to loopback. No CORS wildcard.
- Identifiers `[A-Za-z0-9][A-Za-z0-9_-]{0,199}`, invalid400. Pydantic field errors422, domain errors409, missing404. Return structured detail, no tracebacks.

Tests use real saved fixtures where available and skip explicitly otherwise. `launch_worker=False` only in tests so real queue state remains testable.
