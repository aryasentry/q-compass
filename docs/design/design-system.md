# Dashboard design

Concept reference: `dashboard-concept.png`, generated for this application before
implementation. It specifies a quiet light laboratory workspace, pale blue-gray
sidebar, navy type, teal actions, sparse borders and repeatable forms.

Tokens: background #FFFFFF, sidebar #EEF3F7, foreground #112344, secondary text
#53657F, primary action #008E99, border #DCE5ED. Native Streamlit sans-serif
controls and Plotly use readable hierarchy. Main width at most 1280px, 4rem top
clearance, restrained corner rounding, side-by-side controls that stack on mobile.

Intentional deviations from the concept: native Streamlit radio navigation,
two-column desktop form, exact investment constraints and budget settings, actual
snapshot date instead of the concept's illustrative placeholder, separate results
tab rather than invented preview charts. No fabricated market data or model
performance from the design image is included in the application.
